# Formidable.fut

Minijuegos de fútbol para el móvil. Web estática (GitHub Pages).

- Multijugador online P2P (PeerJS / WebRTC cifrado), salas por código, el anfitrión es la autoridad.
- Sin servidor propio ni base de datos; nada personal se guarda fuera del navegador.
- CSP estricta: solo scripts propios; conexiones a la propia web y al servidor de señalización de PeerJS.
